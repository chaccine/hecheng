# 元件合成 2.0

一款手机竖屏的合成小游戏：同级电子元件碰在一起就会合成更高级的元件，从电阻一路合成到 CPU。

在线试玩：https://chaccine.github.io/hecheng/

## 手感与解压更新

- 落地挤压回弹、合成顿帧与轻微震屏（尊重“减少动态效果”设置）
- 连击：短时间内连续合成形成 Combo ×N，分数倍率提升，合成音阶随连击升高
- 按尺寸区分的碰撞音效，合成 CPU 时有高光音效与柔光
- 清屏：每局 1 次，所有元件依次爆开并计分，合成 15 次后重新充能
- 解锁新元件改为底部轻提示，不再暂停游戏或打断连击
- 结算新增 合成次数 / 最高连击 / 最高元件；声音设置可调音效与音乐音量

## 2.0 更新
- 暖色台灯光影风格，元件更写实精致。
- 新增标题页、卡牌式解锁动画、柔和合成光效。
- 更柔和的音效，可选背景音乐（默认关闭），支持轻微震动反馈。

## 玩法
- 点击或左右拖动瞄准，松手让元件落下。
- 合成链：电阻 → 电容 → 电感 → 二极管 → 三极管 → MOSFET → 运放 → 单片机 → FPGA → CPU。
- 元件在红色警戒线以上停留 2 秒，游戏结束。
- 最高分和元件图鉴保存在本机浏览器里。

## 摇摆模式

标题页点击「摇摆模式」开始独立的一局；「开始」仍进入原来的普通模式，重力、瞄准和计分规则不变。

- 手机竖屏为主，轻轻左右倾斜手机，元件会顺着重力滚动。以 `gamma` 为主，`beta` 小幅调整灵敏度；支持按 `screen.orientation.angle`（旧设备用 `window.orientation`）换算横屏方向。
- iOS 等需要授权的浏览器会显示「启用体感」，点击后才调用 `DeviceOrientationEvent.requestPermission()`。体感需 HTTPS 或本机 localhost；拒绝授权、接口不支持、调用失败或没有传感器数据时，会显示中文提示，仍可使用模拟操作。
- 电脑按住 **← / → 或 A / D** 模拟倾斜；手机和电脑也可**左右拖动棋盘上方的水平仪**。模拟操作松手后平滑回正。真实体感持续有数据时，松手后交还手机倾斜控制。
- 棋盘上的点击、拖动仍用于瞄准和落子；空格 / Enter 落子。摇摆模式的左右方向键用于倾斜，普通模式仍用它们移动瞄准位置。
- 「摇摆：开 / 关」可随时切换；关闭后重力立即恢复垂直向下。已有元件会保留惯性，关闭摇摆仍属于摇摆模式，不会改用普通最高分。
- 水平仪显示实际重力偏角。左右倾斜有 **3° 死区**，约 **180ms 平滑阻尼**，最大偏角 **38°**；重力大小保持不变。摇摆模式单独采用 120Hz 物理子步和球速限制，配合原有厚墙避免穿墙。暂停、失焦、切屏及转屏会清除输入，避免按键卡住。
- 普通最高分继续保存于 `hecheng-best`，摇摆最高分使用 `hecheng-tilt-best`。标题页分别显示两者，结算显示当前模式最高分，「再来一局」保留模式。元件图鉴共用。

### 本地测试

用 Python 选择空闲端口，再启动独立服务器（不要终止已有服务器）：

```sh
python3 -c 'import socket; s=socket.socket(); s.bind(("127.0.0.1",0)); print(s.getsockname()[1]); s.close()'
# 将下行的 <端口> 替换为输出值；若恰好被占用，重新选择。
python3 -m http.server <端口> --bind 127.0.0.1
```

用 Playwright headless MCP 打开 `http://127.0.0.1:<端口>/`，再以 `browser_run_code_unsafe` 的 `filename` 参数运行 `tests/tilt.playwright.js`。脚本创建独立的 390×844、`hasTouch: true` 浏览器 context，不改日常浏览器存档；截图保存到 `/workspace/hecheng/shots-tilt/`（在其他目录运行时请调整脚本路径并先创建截图目录）。返回值列出检查结果：

- 方向键、A/D 侧向漂移和休眠唤醒；松手回正。
- 合成 `deviceorientation` 事件，`gamma=30/-30` 向两侧漂移；`gamma=±2`、`beta=60` 不产生死区漂移；横屏 90° 映射。
- 真正的触摸事件拖动水平仪，无误落子；开关、暂停和恢复。
- 最大正负倾角各连续 8 秒，检查 6 个不同大小元件的墙内位置（允许物理解算的 0.5px 接触误差）。
- 独立存档、标题 / 结算 / 重开、普通模式回归；无控制台错误和未捕获异常。
- 模拟 iOS 授权通过 / 拒绝 / 异常，验证调用位于点击手势中；无接口时的中文回退。

无头测试使用合成传感器数据和模拟授权，不能替代真机检查。发布前请在 HTTPS 下用 iPhone Safari 实测系统授权弹窗、拒绝后操作，以及 Android 的横竖屏切换和传感器手感。截图涵盖标题、水平仪、左右漂移、关闭、权限回退、普通模式和摇摆结算。

## 技术
纯 HTML / CSS / JavaScript，物理引擎使用本地附带的 [Matter.js](https://brm.io/matter-js/)（MIT 许可），无需构建或后端。`tilt.js` 负责体感 / 模拟输入和水平仪，`game.js` 负责模式、存档与物理步进。
